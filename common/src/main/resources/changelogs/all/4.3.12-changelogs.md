## Version Release v4.3.12 MC-1.20.1

### Additions
- Added `PercentageRangedAttribute` which works just like `RangedAttribute` but displays as a % in the tooltip
- Added `IAlwaysTickingItem`, a powerful interface for adding ItemStack ticking in different scopes
  - Originally created for a single mod feature of an AZURUNE mod though it's too good to not have within the library itself
  - The documentation for using this can be found in the interface class itself, so read up there if you want to know how to use it

### Fixes
- Fixed several crashes involving registry freezes on Fabric
