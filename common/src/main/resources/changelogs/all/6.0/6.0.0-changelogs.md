## Version Release v6.0.0 MC-1.21.1

### Important
- This version of RunicLib may cause breaking changes with older versions of mods that use this as a dependant (be sure to update!)
 AZURUNE mods that require this version of RunicLib to fix these issues should be released by the time this version is available

### Breaking Changes
- Updated class name `RLMobEffects.java` to `RLEffects.java`
- Removed multiple effects:
  - `runiclib:lesser_strength`
  - `runiclib:lesser_weakness`
  - `runiclib:caffeinated`
  - `runiclib:caffeine_crash`
  - `runiclib:adrenaline` (along with `AdrenalineEffect.java`)
  - `runiclib:retaliation`
  - `runiclib:burning_thorns`
  - `runiclib:traversal` (along with `TraversalEffect.java`)
  - `runiclib:shatterspleen`
  - `runiclib:venom` (along with `VenomEffect.java` and the `runiclib:venom` damage type)
  - `runiclib:blood_clot`
  - `runiclib:trail_blazing` (along with `TrailBlazingEffect.java`)
  - `runiclib:pyromaniac` (along with `PyromaniacEffect.java`)
- Removed multiple attributes:
  - `runiclib:magic_resistance`, `runiclib:blast_resistance`, `runiclib:elemental_resistance`, and `runiclib:physical_resistance`

### Library Updates
- Added gameDir path to RLPlatformHelper, this gets the game path of the current mod loader
- Added several new functions to RLNetworkHelper
- Runiconfig is now in the `.json5` format instead of the previously used `.json` format
    - Runiconfig can now support strings and enums config values
    - Configs are now registered under a config categories (`ConfigCategory.java`)
        - `.value()` sets a config's value type, comment, and default value
        - `.intValue()`, `.floatValue()`, `.doubleValue()`, sets a config's value type, comment, a minimum to maximum range, and default value
        - `Runiconfig.category()` creates and sets the name of a config category
    - Added `ConfigValue.java`
        - `.getValue()` gets a config's value
        - `.defaultValue()` gets a config's default value
        - `.getId()` gets the config value's id
        - `.getComment()` gets a config's comment
    - Added `NumberConfigValue.java`
        - `.getMin()` gets the config's minimum value
        - `.getMax()` gets the config's maximum value

### Changes
- Changed the id of the configuration `rlCommandsEnabled` to `runicLibCommands`
- `AOEEffect.java` can now optionally determine whether the given effect is ambient and visible, by default `effectAmbient` is false and `effectVisible` is true

### Miscellaneous Updates
- Added a new RunicLib Cape button to the Skin Customization menu, this allows players to cycle through their contributor capes
    - This button will only appear if the player has at least one contributor cape added to their player uuid
- Updated several contributor cape textures
- Updated textures of multiple effects:
  - Creative Shock
  - Berserk
  - Brimstone Vision
  - Chronos
  - Tempus
  - Perception
  - Confusion
- Tweaked colors on `requires_runiclib.png` and `requires_runiclib_enlarged.png`
