## Version Release v6.0.0 MC-1.21.1

### Important
- This version of RunicLib may cause breaking changes with older versions of mods that use this as a dependant (be sure to update!)
 AZURUNE mods that require this version of RunicLib to fix these issues should be released by the time this version is available

### Breaking Changes
- Updated class name `RLMobEffects.java` to `RLEffects.java`

### Additions
- Added a new RunicLib Cape button to the Skin Customization menu, this allows players to cycle through their contributor capes
  - This button will only appear if the player has at least one contributor cape added to their player uuid
  - Added new contributor capes for each AZURUNE project with contributors
  - Capes have been given to contributors with known Minecraft accounts, if you have contributed to an AZURUNE project and have a linked GitHub to your Discord please message @yirmiri if you'd like a cape
- Added gameDir path to RLPlatformHelper, this gets the game path of the current mod loader

### Changes
- Added several new functions to RLNetworkHelper
- Changed the id of the configuration `rlCommandsEnabled` to `runicLibCommands`

### Tweaks
- Tweaked colors on `requires_runiclib.png` and `requires_runiclib_enlarged.png`
- Updated several contributor cape textures
